# Meta-Stamp Pockets

**Licensing and receipts for AI agent access to creator content.**

When an AI agent comes to Meta-Stamp for a piece of content, the visit goes on the record. A licensed pull returns the content with a receipt. A refused one returns a receipt that says no. Either way, the owner's ledger gets the same entry: who, when, which asset.

One visit, two receipts, one independent record. That's the two-sided ledger.

## Pricing

The owner sets the price, per asset.

## What a license covers

A paid pull licenses use in generation, retrieval and inference. Training is not included; it takes a separate license.
